## 🎓 Flujo de Lectura Recomendado

### Para Nuevos Desarrolladores:
1. Lee el **Repo Tour** para familiarizarte con la estructura
2. Sigue la **Guía de Desarrollo** para configurar tu entorno
3. Explora la **Arquitectura** para entender el diseño del sistema
4. Consulta la **API** cuando necesites integrar con el backend

### Para DevOps/Administradores:
1. Revisa **Despliegue** para opciones de distribución
2. Consulta **Base de Datos** para gestión y backups
3. Usa **Troubleshooting** para resolver problemas

### Para Contribuidores:
1. Lee **Arquitectura** y **Repo Tour** primero
2. Configura con **Guía de Desarrollo**
3. Consulta **Roles y Seguridad** antes de modificar permisos
4. Prueba tus cambios con **Troubleshooting** como referencia
