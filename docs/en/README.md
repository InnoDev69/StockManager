## Recommended Reading Flow

### For New Developers:
1. Read the **Repo Tour** to familiarize yourself with the structure
2. Follow the **Development Guide** to configure your environment
3. Explore the **Architecture** to understand system design
4. Consult the **API** when you need to integrate with the backend

### For DevOps/Administrators:
1. Review **Deployment** for distribution options
2. Consult **Database** for management and backups
3. Use **Troubleshooting** to resolve issues

### For Contributors:
1. Read **Architecture** and **Repo Tour** first
2. Set up with **Development Guide**
3. Consult **Roles & Security** before modifying permissions
4. Test your changes with **Troubleshooting** as reference
