Centro de Ayuda - Stockly

Bienvenido al Centro de Ayuda de Stockly

Este manual completo te guiará paso a paso a través de todas las funcionalidades de nuestro sistema de gestión de inventario y ventas para almacenes. Ya sea que seas un usuario principiante o un administrador experimentado, encontrarás información detallada sobre cómo utilizar cada módulo efectivamente. Haz clic en cualquier sección para expandirla y obtener instrucciones específicas. Si tienes dudas adicionales, consulta la sección de "Preguntas Frecuentes" al final.

Dashboard - Panel Principal

Tu Panel de Control - El Corazón del Almacén

El Dashboard es tu primera línea de información. Es la pantalla que ves al iniciar sesión en Stockly y funciona como un panel de control centralizado. Aquí obtienes un resumen ejecutivo del estado actual de tu almacén en tiempo real, permitiéndote tomar decisiones rápidas e informadas basadas en datos precisos y actualizados constantemente.

¿Qué Información Verás en el Dashboard?

  • 4 Tarjetas de Métricas Clave: En la parte superior, encontrarás cuatro tarjetas que muestran información crítica en tiempo real:
    • Productos Totales: Cantidad total de artículos diferentes registrados en tu almacén
    • Stock Bajo: Número de productos que han alcanzado sus niveles de alerta (stock mínimo)
    • Productos que Expiran Pronto: Artículos con fecha de vencimiento dentro de los próximos 30 días
    • Ventas del Día: Ingresos totales generados en las últimas 24 horas
  • 3 Botones de Acceso Rápido: Accesos directos a las funciones más utilizadas para acelerar tu flujo de trabajo
  • Barra de Búsqueda Avanzada: Encuentra cualquier producto rápidamente escribiendo su nombre, código de barras o SKU
  • Sistema de Filtros: Visualiza productos por estado (Disponibles, Bajo Stock, Agotados) con un solo clic
  • Tabla de Productos en Alerta: Una lista detallada de todos los artículos con stock crítico que requieren atención inmediata

¿Por Qué es Importante Revisar el Dashboard Regularmente?

El Dashboard te mantiene informado sobre el estado operativo de tu almacén. Permite identificar problemas potenciales antes de que se conviertan en crisis: saber qué productos están a punto de agotarse, cuáles están próximos a vencer, y cuál es tu rendimiento de ventas diario. Esta información es crucial para la toma de decisiones relacionadas con reorders (pedidos de reabastecimiento), gestión de inventario y planificación de operaciones.

Guía Paso a Paso para Usar el Dashboard

  1. Al Iniciar Sesión: Tómate 30 segundos para revisar las 4 tarjetas en la parte superior. Esto te da un panorama general inmediato del estado del almacén. Si notas números en rojo o alertas, significa que hay situaciones que necesitan tu atención.
  2. Identificar Problemas Prioritarios: Si la tarjeta de "Productos que Expiran Pronto" muestra números elevados, considera promocionar esos productos. Si el stock bajo es alto, es momento de hacer pedidos a tus proveedores.
  3. Usar los Botones de Acceso Rápido: Estos botones te llevan directamente a donde necesitas estar. Haz clic en "Nueva Venta" para registrar una transacción, "Historial" para revisar ventas Anteriores, o "Administrar Productos" para editar tu inventario.
  4. Buscar Productos Específicos: Si necesitas información sobre un producto en particular, escribe su nombre en la barra de búsqueda. El sistema filtrará automáticamente los resultados mientras escribes (búsqueda en tiempo real).
  5. Aplicar Filtros por Estado: Usa el selector de "Estado" para ver solo los productos que te interesan. Por ejemplo, si solo quieres ver productos con bajo stock para hacer un reorder rápido, selecciona "Bajo Stock" y verás solo esos artículos.
  6. Revisar la Tabla de Alerta Detallada: Desplázate hacia abajo para ver la tabla completa de productos con stock bajo. Esta tabla muestra cantidad actual, stock mínimo recomendado, y otros detalles útiles para tmar decisiones de reabastecimiento.
  7. Analizar Tendencias: Si revisas el dashboard diariamente, notarás patrones. Algunos productos se venden más en ciertos días de la semana, lo que te ayuda a planificar mejor tus órdenes de compra.

Consejos Profesionales para Maximizar tu Eficiencia

  • Revisa el dashboard cada mañana antes de iniciar operaciones para planificar tu día
  • Si varias productos muestran stock bajo, no esperes a que se agoten: contacta a proveedores inmediatamente
  • Los productos que expiran pronto deben tener prioridad: ofrece descuentos o promociones para venderlos rápidamente
  • Usa la métrica de "Ventas del Día" para evaluar el desempeño diario y motivar a tu equipo de ventas
Historial de Ventas - Registro Transaccional

Sistema Integral de Transacciones Comerciales

El módulo de Historial de Ventas es el corazón operativo de Stockly. Aquí registras cada venta realizada y mantienes un registro completo y auditable de todas las transacciones comerciales. Este sistema es como tu "libro de caja digital", garantizando que cada movimiento de inventario y dinero quede documentado para auditoría, reportes fiscales, y análisis de negocio.

Componentes Principales de la Sección

  • 3 Tarjetas de Estadísticas Sumarias: Resumen numérico que te permite ver el rendimiento de tu negocio a primera vista:
    • Ingresos Totales: Suma total del dinero generado por todas las ventas en el período visualizado
    • Número de Transacciones: Cantidad de operaciones de venta realizadas (útil para calcular ticket promedio)
    • Unidades Vendidas: Total de items (productos) que salieron del almacén
  • Sistema Avanzado de Filtros: Herramientas para buscar transacciones específicas por múltiples criterios:
    • Rango de Fechas (desde-hasta) para análisis de períodos específicos
    • Nombre de Producto para ver todas las ventas de un artículo particular
    • Vendedor/Responsable para revisar el desempeño de cada miembro del equipo
    • Tipo de Pago para conciliar dinero en efectivo, tarjeta, o crédito
  • Tabla Detallada de Transacciones: Registro completo con todos los detalles de cada venta (fecha, hora, productos, cantidades, totales)
  • Función de Exportación CSV: Descarga todos los datos en formato Excel para análisis profundo, presentaciones, o respaldo en otros sistemas

Procedimiento Detallado: Cómo Registrar una Nueva Venta

  1. Paso 1 - Iniciar la Venta: Busca el botón principal "Registrar Venta" o "Nueva Venta" en la interfaz. Este botón abrirá un formulario modal (ventana pequeña) donde completarás los detalles de la transacción.
  2. Paso 2 - Información del Cliente (Opcional): Si lo deseas, selecciona o busca al cliente que realiza la compra. Este campo es completamente opcional: puedes dejar en blanco si es una venta a consumidor final o si no necesitas registrar el cliente específico. Si tienes una base de clientes, seleccionar el cliente facilita seguimiento para ventas futuras.
  3. Paso 3 - Agregar Productos: Busca cada producto que se venderá escribiendo su nombre, código de barras o SKU. El sistema te mostrará coincidencias en tiempo real. Selecciona el producto correcto de la lista:
    • El sistema verificará automáticamente que hay stock disponible
    • Si no hay stock suficiente, te mostrará una advertencia
    • El precio se cargará automáticamente desde el registro del producto
  4. Paso 4 - Indicar Cantidades: Para cada producto, especifica cuántas unidades se están vendiendo. El sistema calculará automáticamente el subtotal (precio unitario × cantidad). Puedes modificar cantidades en tiempo real y ver cómo cambia el total.
  5. Paso 5 - Seleccionar Método de Pago: Elige cómo el cliente está pagando la compra:
    • Efectivo: Pago en dinero físico, generalmente de inmediato
    • Tarjeta: Pagos con débito o crédito (verifica si necesitas registrar número de referencia)
    • Nota de Crédito: El cliente paga posteriormente (genera una deuda)
    • Otros: Transferencia, cheque, u otros métodos disponibles en tu configuración
  6. Paso 6 - Revisar Resumen: Antes de confirmar, revisa que todo sea correcto:
    • Productos seleccionados y cantidades correctas
    • Total calculado correctamente
    • Método de pago registrado
  7. Paso 7 - Confirmar y Guardar: Haz clic en "Registrar Venta" o "Confirmar". El sistema procesará la transacción, actualizará el inventario automáticamente, generará un recibo (si está configurado), y la venta aparecerá inmediatamente en el historial.

Cómo Buscar y Filtrar Ventas Anteriores

  1. Por Período de Tiempo: Usa los campos de "Fecha Desde" y "Fecha Hasta" para limitar resultados a un rango específico. Por ejemplo, para análisis de ingresos mensuales, selecciona el primer y último día del mes.
  2. Por Producto Específico: Si necesitas saber cuány de un artículo en particular se vendió, escribe el nombre del producto. Verás todas las transacciones que incluyen ese producto, el total unitios vendidos y el dinero generado por ese artículo.
  3. Por Vendedor/Responsable: Esto es útil para evaluar desempeño individual. Puedes ver todas las ventas realizadas por una persona específica, su total de transacciones y revenue generado.
  4. Aplicar Filtros: Una vez ingresados los criterios, haz clic en "Filtrar" o "Buscar". Los resultados se actualizarán automáticamente mostrando solo las transacciones que coincidan con tus criterios.
  5. Limpiar Búsqueda: Si necesitas volver a ver todas las ventas sin filtros, haz clic en "Limpiar" o "Ver Todo". Esto restaurará la vista completa del historial.

Exportar Datos para Análisis Externos

El botón "Exportar CSV" descarga tu historial de ventas en formato de archivo Excel (.csv). Esto es invaluable para:

  • Análisis profundo en Excel con gráficos y tablas dinámicas
  • Reportes mensuales para contador o asesor fiscal
  • Presentaciones a accionistas o durante decisiones estratégicas
  • Respaldo en sistemas externos o integración con otras herramientas
  • Archivo de auditoría para comprobantes fiscales (importante para impuestos)

Recomendaciones Operativas

  • Registra CADA venta al momento de ocurrir, no acumules para el final del día
  • Si cometes un error, NO intentes editar: registra una nota o contacta admin para corrección
  • Revisa el historial semanalmente para identificar productos que venden rápidamente (reabastecer) y lentamente (promover/descontar)
  • Para clientes frecuentes, siempre registra el cliente (ayuda a generar histórico y lealtad)

Gestión de Inventario - Administración de Productos (Admin)

Panel de Control de Productos y Stock

Nota: Esta sección es solo visible para administradores. El panel de Gestión de Inventario es el control maestro de todos tus productos. Aquí creas nuevos artículos, actualizas información existente, defines niveles de stock mínimo, estableces precios, y monitoreas la salud general de tu inventario. Este es el módulo más crítico para asegurar que las operaciones de venta funcionen sin problemas.

Componentes del Panel de Inventario

  • Formulario Rápido de Creación: Ubicado en la parte superior, permite agregar nuevos productos sin salir de la página
  • 4 Tarjetas de Estadísticas del Inventario:
    • Total de Productos: Cantidad total de SKUs (artículos diferentes) en tu sistema
    • En Stock: Productos con cantidad superior al nivel de stock mínimo (situación saludable)
    • Stock Bajo: Productos que alcanzaron el nivel mínimo y requieren reabastecimiento inmediato
    • Sin Stock: Productos con cero unidades disponibles (no pueden venderse hasta recibir reorden)
  • Tabla Completa de Productos: Lista exhaustiva con todos los campos de cada artículo
  • Herramientas de Búsqueda y Filtrado: Encuentra productos rápidamente por nombre, código, o estado
  • Función de Importación Masiva: Carga múltiples productos desde un archivo CSV en una sola operación

Procedimiento Detallado: Crear un Nuevo Producto

Cada producto en tu almacén necesita información precisa. Aquí está exactamente qué completar en cada campo:

  1. Código de Barras (o SKU): Este es el identificador único del producto. Tienes dos opciones:
    • Generar Automáticamente: Haz clic en "Generar" y el sistema asignará un código único numérico (ej: PRD000001)
    • Ingresar Manualmente: Si tienes códigos EAN propios de proveedores o códigos estándar, ingrésalos aquí
    • Importante: Cada código debe ser ÚNICO. El sistema no permite duplicados.
  2. Nombre del Producto: Descripción clara y sin ambigüedades. Ejemplos buenos: "Caja Cartón 20x15x10cm" o "Tornillo M8x25 Acero Inoxidable". Evita solo "Caja" o "Tornillo" porque es confuso cuando hay muchos tipos.
  3. Descripción (Opcional): Espacio para detalles adicionales como especificaciones técnicas, marca, origen, o notas especiales. Puede no requerirse pero es útil para tu equipo de almacén.
  4. Stock Inicial / Cantidad Actual: Cuántas unidades de este producto tienes disponibles AHORA. Si es un producto nuevo que no tienes en existencia todavía, deja en cero.
  5. Stock Mínimo (Cantidad de Alerta): ESTE ES EL CAMPO MÁS IMPORTANTE. Aquí defines en qué cantidad el sistema genera alertas automáticas de "bajo stock". Por ejemplo:
    • Si vendes 20 unidades por semana y te toma 2 semanas recibir reorden: stock mínimo = 40
    • Si es un producto que vende rápido: podrías poner mínimo más alto
    • Si es producto lento que raramente vende: mínimo puede ser 5 unidades
  6. Precio de Venta Unitario: El precio en que vendes UNA unidad del producto. El sistema calculará automáticamente subtotales cuando se venda múltiples unidades. Este precio debe incluir márgenes de ganancia.
  7. Fecha de Vencimiento (Opcional): Si el producto tiene fecha de expiración (alimentos, medicinas, químicos), ingresa aquí. El sistema generará alertas automáticas cuando falte un mes para vencer. Si el producto no vence, deja este campo vacío.

Procedimiento: Editar un Producto Existente

  1. Ubica el producto en la tabla (usa búsqueda si hay muchos)
  2. Haz clic en el botón "Editar" (icono de lápiz) en su fila
  3. Se abrirá un formulario con los datos actuales del producto
  4. Modifica solo los campos que necesitan cambios (pueden ser muchos campos o solo uno)
  5. Haz clic en "Guardar Cambios" para confirmar
  6. El sistema actualizará inmediatamente la información en el inventario
  7. Todos los usuarios verán los cambios en tiempo real (incluyendo vendedores que buscan precio)

Búsqueda y Filtrado Avanzado de Productos

Escenarios prácticos y cómo abordarlos:

  • "Necesito ver todos los productos con bajo stock para hacer un pedido urgente"
    → Usa filtro Estado = "Stock Bajo", verás solo los 5-10 productos que requieren reorden inmediato
  • "Venimos a rebajar precios de productos que no venden"
    → Busca por nombre, edita precio, guarda. El nuevo precio se refleja automáticamente
  • "Un cliente pide un producto específico, pero no recuerdo el código"
    → Escriba el nombre del producto en búsqueda, encontrarás todas las variaciones con ese nombre
  • "Necesito un reporte de todos los productos sin stock"
    → Filtro Estado = "Sin Stock", luego exporta esos resultados si quieres en Excel

Importar Múltiples Productos desde CSV (Carga Masiva)

Si tienes 100+ productos y no quieres crearlos manualmente uno por uno, puedes importarlos del proveedor. Aquí el proceso:

  1. Preparar el Archivo CSV: Tu archivo Excel debe tener EXACTAMENTE estas columnas en este orden:
    barcode | name | description | quantity | min_quantity | price | expiration_date
    Ejemplos de línea válida: PRD123456 | Caja Cartón 20x15 | Caja reforzada | 100 | 20 | 2.50 | 2026-12-31
  2. Encontrar Sección de Importación: En el panel de Inventario, busca el botón "Importar desde CSV" o "Cargar Masivamente"
  3. Cargar tu Archivo: Haz clic en "Seleccionar Archivo", elige tu CSV preparado desde tu computadora
  4. Validación Automática: El sistema verificará que el formato sea correcto antes de importar. Si hay errores, te mostrará exactamente qué líneas fallan y por qué
  5. Confirmar Importación: Si todo está correcto, haz clic en "Importar". Los productos se crearán automáticamente en tu sistema en cuestión de segundos, incluso si son miles
  6. Verificación Post-Importación: Revisa que aparezcan todos los productos esperados en tu tabla. Si algunos faltan o tienen datos incorrectos, edita manualmente o intenta importar de nuevo

Estados de Stock: Qué Significan los Colores

  • En Stock (Verde): Cantidad es MAYOR que el stock mínimo. Situación normal, puedes vender sin problemas. Estos productos no requieren reorden urgente.
  • Stock Bajo (Amarillo): Cantidad es IGUAL O CERCANA al stock mínimo. Alerta: necesitas hacer reorden pronto para evitar quedarte sin existencias. Prioriza estos productos.
  • Sin Stock (Rojo): Cantidad es CERO o negativa. Problema: NO puedes vender este producto. Los vendedores verán que no está disponible. Reorden URGENTE necesario o descontinúa el producto si no lo vas a reabastecer.

Mejores Prácticas para Gestión de Inventario

  • Actualiza cantidades después de cada venta (el sistema lo hace automáticamente)
  • Revisa diariamente el Dashboard para avisos de bajo stock
  • Ajusta stock mínimo basado en velocidad real de venta (observa datos historicos)
  • Elimina productos discontinuados para mantener el catálogo limpio
  • Revisa precios mensualmente para ser competitivo
  • Usa códigos de barras consistentemente para evitar duplicados accidentales

Notificaciones - Sistema de Alertas

Centro de Alertas y Comunicaciones del Sistema

Stockly incluye un sistema inteligente de notificaciones que monitorea constantemente tu almacén y te alerta automáticamente cuando ocurren eventos importantes. En lugar de que tengas que estar verificando manualmente cada métrica, el sistema te notifica proactivamente sobre problemas, oportunidades, y eventos completados.

Tipos de Notificaciones y Su Significado

  • Información (Azul): Notificaciones de estado general y cambios del sistema sin urgencia. Ejemplos: "Venta registrada", "Usuario creado", "Producto agregado". Estas no requieren acción inmediata, solo informan sobre operaciones completadas.
  • Éxito (Verde): Operaciones completadas exitosamente. Ejemplos: "Importación CSV completada con 152 productos", "Inventario actualizado correctamente", "Reporte exportado". Estas confirman que todo funcionó como esperado.
  • Aviso (Amarillo/Naranja): Situaciones que requieren tu atención pero no son críticas inmediatamente. Ejemplos: "Stock bajo: Solo 5 cajas de Cartón disponibles", "Producto vence en 25 días", "Alta concentración en un solo producto (80% de ventas)". Debes actuar pronto pero tienes tiempo para planificar.
  • Error (Rojo): Problemas críticos que requieren acción inmediata. Ejemplos: "Stock insuficiente", "CSV con formato incorrecto", "Error en importación de datos". Estos bloquean operaciones o indican problemas serios.

Cómo Acceder y Gestionar Notificaciones

  1. Ubicar el Centro de Notificaciones: Busca el icono de campana en la barra superior derecha. Un número en rojo indica cuántas notificaciones NO LEÍDAS tienes.
  2. Abrir tu Centro: Haz clic en la campana. Se desplegará una lista con tus últimas notificaciones (las más recientes primero).
  3. Marcar como Leída: Cuando lees una notificación, puedes marcarla como "leída" (desaparece el indicador rojo). Esto es útil para saber cuáles ya procesaste.
  4. Filtrar por Tipo: En la sección de Notificaciones, usa el selector para ver solo:
    • Todas las notificaciones
    • Solo Información
    • Solo Éxito
    • Solo Avisos
    • Solo Errores
  5. Filtrar por Estado de Lectura: Ver notificaciones por:
    • Sin Leer (información nueva que aún no procesas)
    • Leídas (ya las viste, pueden archivarse)
  6. Marcar Todo como Leído: Si tienes 50+ notificaciones, usa "Marcar Todas como Leídas" para limpiar el contador y empezar limpio
  7. Acción Rápida: Algunas notificaciones tienen un botón que te lleva directamente al lugar donde actuar. Por ejemplo, una notificación de "Stock bajo" puede tener un botón "Ir a Inventario" que te lleva directo al producto.

Ejemplos Reales de Notificaciones que Recibirás

  • Stock Bajo: "Stock bajo en Tubo PVC 1/2" - Quedan 3 unidades, stock mínimo es 10. Acción recomendada: Contacta proveedor para reorder.
  • Venta Completada: "Venta registrada correctamente - Caja Cartón + Cemento - Total $135.00". Confirmación de que la transacción se procesó exitosamente.
  • Inventario Crítico: "Inventario bajo en 8 productos - Se recomienda hacer pedidos ahora". Alerta agregada cuando múltiples productos necesitan reorden.
  • Vencimiento Próximo: "Producto 'Pintura Acrylic' vence en 12 días. Solo quedan 15 unidades". Urgencia máxima para vender estos productos antes de que pierdan valor.
  • Cambio de Usuario: "Admin cambió nombre de producto: 'Caja Pequeña' → 'Caja Pequeña 5x5x3'". Información de auditoría que registra cambios importantes.
  • Error de Sistema: "Error al importar CSV: Línea 45 - Código de barras duplicado (PRD000152)". Problema técnico que requiere corrección.

Por Qué Las Notificaciones Son Críticas

Las notificaciones te previenen de problemas antes de que se conviertan en crisis. Sin un sistema de alertas, podrías descubrir que se agotó un producto importante solo cuando un cliente llega a comprarlo. Con notificaciones, tienes días o semanas de avance para reaccionar. Es como tener un asistente que monitorea tu almacén 24/7.

Consejo: Revisa tu centro de notificaciones cada mañana antes de iniciar operaciones. Esto toma 2-3 minutos y te permite identificar dos qué problemas o alertas necesitan atención ese día.

Métricas y Reportes - Análisis Empresarial (Admin)

Análisis Avanzado del Desempeño de tu Negocio

Nota: Esta sección es solo para administradores. El módulo de Métricas transforma los datos brutos de transacciones en insights accionables. Aquí obtienes un análisis detallado sobre cuánto dinero ganas, cuántas operaciones realizas, cuál es tu ticket promedio, y cuáles son tus productos estrella. Estos datos son cruciales para decisiones estratégicas: expandir, reducir, o cambiar tu enfoque de ventas.

Las 4 Métricas Principales Explicadas en Detalle

  • Ingresos Totales: La suma total de dinero que has recaudado en el período. Este número te muestra "qué tan bien te fue". Un aumento semanal indica que el negocio crece. Una disminución es señal de que necesitas investigar: productos no venden, equipo menos motivado, mercado cambió. Compara con el mes anterior para ver progresión.
  • Total de Ventas (Número de Transacciones): Cuántas operaciones de venta completaste. Si tienes $1,000 en ingresos pero solo 2 ventas, significa que tuviste operaciones grandes pero pocas. Si tienes $1,000 pero 100 ventas, significa muchas operaciones pequeñas. Esto afecta tu estrategia: más ventas requiere más equipo; ventas grandes requieren mejor servicio al cliente.
  • Ticket Promedio: Dinero promedio por cada venta (Ingresos ÷ Número de Ventas). Si es bajo ($5-$10 por venta), enfócate en vender múltiples items por cliente. Si es alto ($100+), mantén esa estrategia pero asegura consistencia. Un ticket promedio creciente es excelente indicador de salud empresarial.
  • Unidades Vendidas (Volumen): Cantidad total de items que salieron del almacén. Un volumen muy alto con ingresos moderados sugiere que vendes muchos productos baratos. Volumen bajo con ingresos altos sugiere productos de alto margen. Ambos son válidos; depende de tu modelo.

Cómo Cambiar el Período de Análisis

  1. Botones de Período Rápido: En la parte superior, encontrarás botones para:
    • "7 Días" → Análisis de la última semana (perfecto para decisiones diarias)
    • "30 Días" → Análisis del mes (estándar para reportes mensuales)
    • "3 Meses" → Trimestre (para decisiones estratégicas)
    • "1 Año" → Año completo (visión de largo plazo)
  2. Período Personalizado: Si quieres un rango específico (ej: "20 de marzo a 15 de abril"), usa los campos "Desde" y "Hasta". Esto es útil para campaigns específicas o análisis especiales.
  3. Aplicar Cambios: Después de seleccionar período, haz clic en "Actualizar" o "Aplicar". Todos los números recalcularán automáticamente para ese rango.
  4. Comparación Automática: El sistema muestra no solo los números actuales, sino también cómo cambiaron comparado al período anterior. Una flecha arriba (↑) significa que mejoraste; flecha abajo (↓) significa que empeoró.

Interpretando Flechas y Porcentajes de Cambio

  • ↑ 25% (Arriba - Verde): Excelente. Tus métricas mejoraron 25% comparado al período anterior. Continúa haciendo lo que estás haciendo; funciona.
  • ↓ 15% (Abajo - Rojo): Preocupante. Caíste 15%. Investiga por qué: ¿Menos ventas? ¿Productos con menos margen? ¿Equipo menos motivado? Necesita acción correctiva.
  • → 0% (Igual - Gris): Neutro. Mantuviste el mismo nivel que el período anterior. Ni crecimiento ni caída; es una meseta. Buena para estabilidad pero sin progreso.

Top 5 Productos Más Vendidos - Tu Tabla de Éxitos

Una tabla muestra los 5 productos que generaron MÁS DINERO (no necesariamente los que más se vendieron en cantidad). Por ejemplo:

  • Producto A: 50 unidades × $2 = $100 (bajo margen, alto volumen)
  • Producto B: 5 unidades × $200 = $1,000 (alto margen, bajo volumen) ← TOP
  • Producto C: 30 unidades × $20 = $600 (margen medio, volumen medio)

Por qué importa: Conocer tus top 5 te dice dónde concentrar esfuerzos. Asegúrate siempre tener suficiente stock de estos productos. Promociona estos para crecer más. Si no están en tu top 5, considera por qué: ¿No está en exhibición? ¿Precio demasiado alto? ¿No es lo que clientes piden?

Exportar Reportes para Presentaciones y Análisis Profundo

El botón "Descargar CSV" o "Exportar Excel" descarga todas tus métricas en formato que puedes abrir en Excel. Esto te permite:

  • Crear gráficos personalizados que Stockly no ofrece nativamente
  • Comparar múltiples períodos lado a lado (enero vs febrero vs marzo)
  • Compartir con contador/asesor fiscal para declaraciones
  • Presentar a inversionistas o junta directiva
  • Respaldar datos para auditoría
  • Consolidar datos de múltiples sucursales (si tienes varias)

Cómo Usar Métricas para Tomar Mejores Decisiones

  • Decisiones de Reorden: Si unproducto está en tu top 5 pero stock bajo, reorden AHORA. No esperes, ese es dinero creciendo en el árbol.
  • Decisiones de Precio: Si un producto tiene bajo ticket promedio pero alto volumen, consider subir precio 10%. Probablemente lo seguirás vendiendo pero con mejor margen.
  • Decisiones de Producto: Productos fuera del top 5 con baja rotación deberían discontinuarse o reformularse, liberando espacio preciosos almacén para productos ganadores.
  • Decisiones de Equipo: Si tasa de transacciones cae pero ingresos suben, significa mejor servicio al cliente (ventas más grandes). Refuerza ese comportamiento.

Sección 2: Seguridad - Cambio de Contraseña

CRÍTICO: Solo tú deberías saber tu contraseña. Cambiarla regularmente es fundamentales para la seguridad. Aquí está el procedimiento detallado:

  1. Paso 1 - Ingresa tu Contraseña Actual: El sistema te pedirá tu contraseña ACTUAL para confirmar que eres realmente tú. Esto previene que alguien que accedió tu cuenta ilegalmente pueda cambiar tu contraseña sin saberlo.
  2. Paso 2 - Crea Nueva Contraseña (Primera Vez): Ingresa tu nueva contraseña. Debe cumplir con requisitos de SEGURIDAD (el sistema te dirá si es débil):
    • Mínimo 8 caracteres (entre más larga, más segura)
    • Al menos 1 MAYÚSCULA (ej: "A")
    • Al menos 1 minúscula (ej: "a")
    • Al menos 1 número (ej: "5")
    • Al menos 1 símbolo especial (ej: "!", "@", "#", "$", "%")
  3. Paso 3 - Confirmar Nueva Contraseña (Segunda Vez): Repite exactamente la misma contraseña. Esto evita typos. Si no coinciden, el sistema te lo indicará.
  4. Paso 4 - Guardar Cambios: Haz clic en "Actualizar Contraseña" o "Cambiar Contraseña". El sistema procesará tu cambio inmediatamente.
  5. Paso 5 - Próximo Acceso: Tu contraseña anterior ya NO funciona. En el próximo login, DEBES usar la NUEVA contraseña. Si la olvidas, usa "Olvidé mi Contraseña" en la pantalla de login.

Guía de Contraseña Segura - Ejemplos

INSEGURAS (No uses):

  • "12345678" ← Solo números
  • "password" ← Palabra muy común
  • "Juan2025" ← Tu nombre + año
  • "ABC123" ← Muy corta (6 caracteres)

SEGURAS (Usa parecidas):

  • "MiAlmac3n!2025" ← Mezcla de todo, fácil de recordar
  • "GestioInventario#789" ← Descripción + números + símbolo
  • "Carb0n.Excel-2024!" ← Compleja y única

Mejores Prácticas de Seguridad

  • Cambia contraseña cada 3 meses: Aunque sea molesto, alguien podría haber visto tu contraseña en algún tiempo. Cambiar regularmente invalida accesos no autorizados.
  • Nunca compartas contraseña: Ni con admin, ni con colegas, ni con IT. Tu contraseña debe ser solo información tuya. Si un admin lo necesita, deben resetearla, no pedírtela.
  • Cierra sesión al terminar: Especialmente en computadoras compartidas (recepción, mostrador). Un clic en "Cerrar Sesión" te desconecta completamente. La siguiente persona deberá hacer login.
  • No uses contraseña en dispositivos públicos: Café, biblioteca, hotel. Hackers pueden instalar keyloggers (dispositivos que graban lo que tipeas).
  • Si sospechas acceso no autorizado: Contacta al administrador immediamente. Cambia contraseña, revisa actividad reciente, valida que tus datos están OK.

Cerrar Sesión de Forma Segura

En la esquina superior derecha o en el menú de Configuración, encontrarás un botón rojo que dice "Cerrar Sesión" o "Logout". Haz clic para salir. Esto es IMPORTANTE especialmente si:

  • Terminaste tu turno
  • Compartiste computadora
  • Te vas a tomar descanso
  • Fin de la jornada
Advertencia: Si cierras el navegador sin hacer "Cerrar Sesión", tu sesión puede permanecer activa. Alguien podría seguir usando tu cuenta si regresa a esa computadora. Siempre cierra sesión explícitamente.

Preguntas Frecuentes - Respuestas Completas

Aquí encontrarás respuestas detalladas a las preguntas más comunes que los usuarios plantean al trabajar con Stockly.

¿Cómo recupero mi contraseña si la olvidé?

Procedimiento:

  1. En la pantalla de login, busca el enlace "¿Olvidaste tu contraseña?" o "Recuperar Contraseña"
  2. Verás un campo donde ingresas tu usuario o email
  3. El sistema enviará un enlace de recuperación a tu email registrado
  4. Revisa tu bandeja de entrada (y carpeta de SPAM, a veces termina ahí)
  5. Haz clic en el enlace del email. Te llevará a una página donde creas una NUEVA contraseña
  6. Recuerda: El enlace suele expirar en 24 horas por seguridad. Si pasó ese tiempo, solicita uno nuevo

Si no recibes email: Contacta al administrador. Puede haber un problema con tu email registrado o configuración del sistema.

¿Cuándo exactamente debo hacer un pedido de reabastecimiento?

Respuesta corta: Cuando el proyecto muestre "STOCK BAJO" - aparecerá en amarillo/naranja en el Dashboard y Inventario.

Respuesta larga:

  1. Cada producto tiene un campo "Stock Mínimo" que tú estableces. Por ejemplo, si Tubo PVC tiene stock mínimo de 20 unidades, cuando llegues a 20 el sistema lo marca como "bajo stock"
  2. El Dashboard mostrará un contador de "Productos en Bajo Stock"
  3. La regla es: Cuando veas "bajo stock", INMEDIATAMENTE contacta a tu proveedor para un nuevo pedido. No esperes a llegar a cero, eso es tarde.
  4. Fórmula profesional: Stock mínimo = (Ventas promedio por día) × (Días de espera para recibir orden)
    Ejemplo: Si vendes 5 tubos/día y tu proveedor tarda 4 días en entregar, stock mínimo debería ser 20.

¿Qué pasa si intento vender un producto que está sin stock?

Respuesta: El sistema te lo impedirá. Aquí está qué pasará:

  • Cuando intentes agregar un producto sin stock al carrito de venta, el sistema mostrará un aviso ROJO
  • No podrás confirmar la venta si las cantidades solicitadas superan el stock disponible
  • Esto previene que vendas lo que no tienes (lo que causaría problemas legales y operacionales)
  • Opciones: (a) Ofrecer al cliente otra fecha cuando llegue el producto, (b) Recomendar un producto alternativo, (c) Tomar su información para hacer un pre-pedido

¿Cómo veo el desempeño de cada vendedor?

Nota: Solo administradores ven todos los vendedores. Los vendedores solo ven sus propias ventas.

  1. Ve a "Historial de Ventas"
  2. En los filtros, selecciona "Vendedor" y elige la persona que quieres analizar
  3. Opcionalmente, también filtra por rango de fechas (ej: solo ventas de este mes)
  4. Verás todas sus transacciones, total dinero generado, número de operaciones
  5. Puedes exportar este reporte en CSV para hacer análisis comparativo entre vendedores

¿Qué significa "Productos que Expiran Pronto"?

Significado: Son productos perecederos (alimentos, medicinas, químicos) cuya fecha de vencimiento está dentro de los próximos 30 días.

Por qué te alertamos: Productos próximos a vencer tienen valor comercial reducido. Un yogurt que vence en 5 días es menos atractivo para el cliente que uno que vence en 3 meses.

Qué hacer:

  • Promoción/Descuento: Ofrece 10-20% menos para vender rápidamente
  • Visibilidad: Ponlos en exhibición prioritaria en la tienda
  • Si no se venden antes de vencer: Debe exponerlos del inventario (waste) y registrar como pérdida (importante para impuestos y reportes)

¿Puedo exportar mis datos y qué formatos soportan?

SÍ, puedes exportar. Prácticamente toda información exportable se descarga en formato CSV (Comma-Separated Values).

¿Qué es CSV? Es un formato de texto plano que cualquier programa (Excel, Google Sheets, softwares accesamiento) puede abrir. Es el estándar universal para intercambiar datos.

Dónde puedo exportar:

  • Historial de Ventas → Descarga "Reporte de Ventas.csv"
  • Inventario → Descarga "Catálogo de Productos.csv"
  • Métricas → Descarga "Análisis de Desempeño.csv"

Una vez descargado, qué puedo hacer: Abierto en Excel, puedes crear gráficos, tablas dinámicas, análisis personalizados. También puedes compartir con contador, inversionistas, o guardar como respaldo.

¿Los datos se actualizam en tiempo real? ¿O hay demoras?

Tiempo real VERDADERO. Cuando registras una venta, INMEDIATAMENTE:

  • El inventario se actualiza (stock disminuye)
  • Los totales de Historial cambian
  • Las Métricas (ingresos, tickets) se recalculan
  • El Dashboard refleja el nuevo estado
  • Todos los usuarios ven los cambios (sin necesidad de actualizar página)

Excepción: Las Métricas que muestran "comparación vs período anterior" pueden tomar 1-2 minutos para recalcular si hay un largo historial. Es normal y por razones de performance.

¿Puedo eliminar o borrar el histórico de ventas?

NO, no puedes. El histórico es PERMANENTE E INMODIFICABLE.

¿Por qué? Razones legales y fiscales. Las autoridades tributarias requieren que mantengas comprobantes de TODAS tus transacciones durante mínimo 3-5 años. Si desaparecen, es evidencia de fraude.

Si cometiste un error en una venta: NO intentes borrarla. Contacta al administrador. Una nota o ajuste puede registrarse pero la venta original permanece como referencia auditada.

¿Cómo funciona el sistema de códigos de barras?

Opciones para códigos:

  1. Generar Automático: Si dejas el campo vacío al crear producto, el sistema genera automáticamente uno. Formato: PRD123456 (único y único).
  2. Código EAN del Proveedor: Si tu proveedor te da códigos oficiales (código de barras standard), ingrésalos. Funciona si tienes lector barcode.
  3. Código Personalizado: Puedes inventar tu propio sistema si tienes buen motivo (ej: formato específico).

Regla de Oro: Cada código debe ser ÚNICO. No puedes tener dos productos con el mismo código (el sistema lo rechazará).

Casos de uso: Códigos de barras acelera mu ventas si tienes lector barcode (escáner). Busca código = más rápido que escribir nombre del producto.

¿Cuáles son los mejores consejos para usar Stockly efectivamente?

  • Revisa Dashboard cada mañana: 2 minutos invirtiendo te evita 2 horas de crisis
  • Registra cada venta INMEDIATAMENTE: No acumules para el final del día
  • Mantén stock mínimo realista: Basado en velocidad de venta actual, no en intuición
  • Revisa Métricas semanalmente: Identifica tendencias temprano
  • Exporta datos mensuales: Respaldo y para decisiones estratégicas
  • Cambia contraseña cada 3 meses: Seguridad personal
  • Comunicate problemas al admin: Somos hogar para mejorar
  • Nunca: Intentes "arreglar" errores borrando datos o sin report
